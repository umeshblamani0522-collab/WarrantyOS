# WarrantyOS Backend

Spring Boot REST API for WarrantyOS.

- Java 21
- Spring Boot 3.2.5
- Maven 3.10.0
- MySQL 8.4
- Spring Security + JWT
- WebSocket/STOMP

Run from this folder:

```cmd
D:\apache-maven-3.10.0\bin\mvn.cmd clean spring-boot:run
```

The backend listens on `http://localhost:8080`.
